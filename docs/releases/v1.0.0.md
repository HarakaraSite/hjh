# hjh v1.0.0

First stable release of hjh, a terminal AI agent harness with a Go core and an
independent TUI.

- CLI and interactive tasks with saved, resumable sessions.
- OpenRouter, OpenCode Go, OpenAI API, and ChatGPT OAuth connections.
- File and command tools, web fetching, and Exa web search.
- Child agents with parallel work, progress reports, and follow-up instructions.
- Editable JavaScript tools and hooks, roles, workspace instructions, and skills.

The Linux/amd64 bundle contains `hjh`, `hjh-tui`, editable extensions, dependency
licenses, and a per-file hash manifest. Go, Python, Node.js, and Deno are not
required to run the bundle.

Download `hjh-linux-amd64.tar.gz` and `SHA256SUMS`, then verify and extract:

```sh
sha256sum -c SHA256SUMS
tar -xzf hjh-linux-amd64.tar.gz
./hjh-linux-amd64/hjh-tui
```

Use `/login` to configure credentials and `/provider` and `/model` to choose a
connection. Content search uses ripgrep or GNU grep; Git inspection requires Git.
